# What's New - FairDealPro

## Suomi (Finnish)

### Parannukset joukkueenjakoon

**Parempi tasapaino ja satunnaisuus**

- Joukkueiden jako on nyt tasapainoisempi kun algoritmi käyttää keskimääräistä taitotasoa
- Lisätty satunnaisuutta samantasoisten pelaajien jakoon - ei enää samanlaisia joukkueita joka kerta!
- Cat 1 pelaajien jako on nyt oikeudenmukaisempi

**Teknisiä parannuksia**

- Optimoitu joukkueenjakoalgoritmi käyttää Fisher-Yates -sekoitusta
- Tasapainoindikaattori näyttää nyt tarkemmin joukkueiden tasapainon

## English

### Team Balancing Improvements

**Better Balance and Randomization**

- Team generation now uses average skill level for more balanced teams
- Added randomization for players with equal skill levels - no more identical teams every time!
- Category 1 player distribution is now more fair

**Technical Improvements**

- Optimized team balancing algorithm uses Fisher-Yates shuffle
- Balance indicator now shows team balance more accurately
